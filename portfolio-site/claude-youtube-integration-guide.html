Claude × YouTube Integration Guide

Claude cannot natively watch YouTube videos. Use MCP servers or connectors to bridge the gap.

1 Video Content & Transcripts

  • YouTube Transcript MCP — install via npx youtube-transcript-mcp
  • Community MCPs — e.g. kimtaeyoon83/mcp-server-youtube-transcript (no API key needed)
  • Manual — copy-paste from YouTube's "Show Transcript" button

2 Channel Analytics & Data

  • vidIQ — connect via https://mcp.vidiq.com/mcp
  • Windsor.ai — pull Analytics data for traffic & engagement
  • Supermetrics — no-code channel data queries

3 Publishing & Automation

  • Blotato — https://mcp.blotato.com/mcp for uploads, titles, thumbnails
  • Upload-Post — full metadata (tags, chapters, visibility)
  • Composio — list videos, subscriber counts, channel actions

✓ Setup Summary

  1. Install / Connect — add the connector in Claude Desktop or via CLI
  2. Authorize — sign in with Google/YouTube via OAuth
  3. Query — ask Claude to analyze URLs or channel data
