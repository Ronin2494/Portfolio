01 / Learn by doing

Six useful skills. Real outcomes.

Choose an outcome and follow the steps. Start with a free plan before deciding whether a paid subscription is worth it.

BEGINNER · 10 MIN

Research with sources

Use an AI assistant to investigate a question and verify the answer using primary sources.

  1. Ask a specific question with location and date.
  2. Request cited sources and links to original documents.
  3. Open the original sources and check the crucial facts.
  4. Ask the assistant to separate known facts from speculation.
Use research prompt ↗
BEGINNER · 8 MIN

Draft and improve writing

Create a useful first draft, then specify the audience, tone and length. Review and edit before publishing.

  1. State the audience and goal.
  2. Provide your rough notes.
  3. Ask for a clear structure and alternative openings.
  4. Correct facts and personalize the result.
BEGINNER · 12 MIN

Generate an image

Describe the subject, composition, lighting and aspect ratio. Iterate on one element at a time.

  1. Choose a tool that offers image creation.
  2. Describe what should appear and what should not.
  3. Refine typography and composition.
  4. Check usage rights and factual accuracy.
BUILDER · 20 MIN

Build a mini web app

Ask for a functioning interface with accessible controls and tests—not just a screenshot.

  1. Describe features and acceptance criteria.
  2. Create a small app and run it locally.
  3. Test desktop, mobile and error cases.
  4. Review security before deployment.
Explore Copilot documentation ↗
BUILDER · 18 MIN

Use AI agents responsibly

Delegate multi-step tasks such as reviewing files or updating a project, while keeping approvals for consequential actions.

  1. Define a measurable goal.
  2. Limit tool permissions.
  3. Require a review before sensitive actions.
  4. Record results and rerun tests.
BEGINNER · 15 MIN

Analyze a spreadsheet

Upload a sample CSV or spreadsheet and ask for a summary, chart and anomalies.

  1. Remove personal or confidential information.
  2. Ask for a data dictionary and quality checks.
  3. Generate charts and explain assumptions.
  4. Validate key calculations.

05 / Common questions

Answers that save time.

Do I need to pay to start learning AI?

No. ChatGPT, Claude, Gemini and GitHub Copilot offer entry-level access in supported locations. Availability and limits vary.

What is the difference between an AI chatbot and an API?

A chatbot is an application for people. An API lets developers integrate an AI model into software. The chatbot subscription generally does not include API usage charges.

Can AI agents operate my accounts?

Some products can connect to tools and perform authorized actions. Review permissions and require approval for sending messages, modifying records, payments, and other consequential changes.

Will this guide automatically update with new models and prices?

Not automatically. This editorial page links to provider-maintained release notes and plan pages for current details. This guide was reviewed in November 2026.
